Expand description

A stored proposal as it was before it was stored, as far as it can be rebuilt.

The stored form has no field for next_epoch_justify_qc, the Cert2 of the block before that the first block of an epoch carries. anchor_cert2 is that certificate when the anchor is that block. The leader signs the leaf commitment, which does not cover the field, so the proposal need not get back the very certificate it came with.
