fn consistent_with(&self, view: ViewNumber, epoch_height: u64) -> bool

Whether the data is consistent, internally and with the certificate’s view.

Checked in check, so a certificate failing it is never recorded as verified and cannot retire its key for other senders. It runs before the genesis exemption, which therefore cannot skip it.

Dyn Compatibility§

This trait is not dyn compatible.

In older versions of Rust, dyn compatibility was called "object safety", so this trait is not object safe.
