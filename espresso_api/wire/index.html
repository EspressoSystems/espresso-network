Module wire 

Source
Expand description

Tide-disco-compatible content negotiation, shared by the axum ports of the tide-disco services (builder, state relay server, orchestrator, light client query service).

Each service keeps its own wire error envelope (the exact Serialize shape its existing clients decode) and describes it to these helpers with a WireFormat impl; the negotiation logic itself (Accept/Content-Type handling, VBS vs JSON, serialization fallbacks) lives only here.
