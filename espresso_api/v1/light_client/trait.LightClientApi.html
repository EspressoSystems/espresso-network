where Self: 'async_trait, 'life0: 'async_trait,

Payload proofs for a set of (from, until) half-open height ranges, which need not be contiguous.

A node catching up over a fragmented set of heights would otherwise pay a round trip per run. The proofs are the same ones the range endpoint returns, in ascending height order.
