pub fn cors_layer() -> CorsLayer
Expand description

The permissive CORS policy tide-disco applied to every response it served, which browser clients (the explorer, the staking UI) depend on. Every axum-migrated service layers this on its router; without it, a browser rejects the response before the page ever sees it.

Apply it as the outermost layer, so it also covers responses generated by middleware rather than a handler (the connection limit’s 429 would otherwise skip it).

allow_methods and allow_headers are only echoed on the OPTIONS preflight, which is where a browser reads them; allow_origin goes out on every response.
