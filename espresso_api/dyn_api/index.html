Module dyn_api 

Source
Expand description

Type-erased mirrors of the crate::v1 API traits.

The router_* builders in crate::axum used to be generic over the state type, so every handler closure, and the aide/axum machinery behind it, was codegened once per concrete state (three in the node binary, plus the test mock). The traits here repeat the v1 traits with their associated types replaced by Erased, which makes them object safe: the routers take an Arc<dyn ...> and are compiled once. Cost at runtime is one virtual call and one box per response.

Each trait has a blanket impl forwarding to the corresponding v1 trait, so every state type gets the erased view for free, and only those forwarders are monomorphized per state.
