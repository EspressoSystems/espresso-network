This crate contains a general request-response protocol. It is used to send requests to a set of recipients and wait for responses.

Constants§

RESPONSE_BUFFER_SIZE 🔒
The number of serialized responses each waiter buffers before drops occur. Only one valid response is needed and batched senders keep re-requesting, so extra responses are free to drop. Kept small because bodies (leaves, merkle trees, VID shares) can be large and every in-flight request pins its own buffer
