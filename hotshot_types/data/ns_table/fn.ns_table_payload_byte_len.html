pub fn ns_table_payload_byte_len(bytes: &[u8]) -> Option<usize>
Expand description

The payload length bytes claims to be the namespace table of: its final offset, or zero for a table with no entries. None if bytes is not a namespace table at all.

parse_ns_table substitutes one namespace spanning the payload both for bytes that are no table and for a table sized for another payload. A verifier that learned the payload’s length from the payload itself must tell the two apart: for a one-namespace payload the substitute is the honest table, so a table claiming a different length would otherwise pass.
