Expand description

Hook that may install stake tables for catchup(target) when the held pair (start-1, start) is more than one epoch below target. Called with (target, start, coordinator). Returns the walk start start', at or above start, or an error, which is logged; the walk then runs from start. The pair (start'-1, start') is held on return, and so is the table of epoch start'-2 (the next install’s block reward reads it). The hook bounds its own duration (no timeout, seed_lock held) and must not await a catchup on this coordinator.
