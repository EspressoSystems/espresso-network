Expand description

Adds node 0’s API, if given, as a catchup provider alongside catchup. From epoch 3 the new protocol fetches epoch root leaves through catchup, so a node without storage or state peers would otherwise wedge at the first epoch boundary. Both providers are queried at once, so a test of catchup itself must leave the API out.
