Module ranges 

Source
Expand description

Fetching objects for many height ranges at once.

The ranges the scanner is missing are often short and scattered, and fetching each one costs a round trip. These requests carry the whole set at once. They resolve like any other fetch, so a peer that cannot serve them is not a dead end: the provider falls back to fetching each range on its own.
