fn init_pruned_height<'life0, 'async_trait>( &'life0 self, _height: u64, ) -> Pin<Box<dyn Future<Output = Result<()>> + Send + 'async_trait>>
where Self: Sync + 'async_trait, 'life0: 'async_trait,

Called with the height of each decided block, before the block is stored.

On a fresh pruned database, the first block above genesis marks the blocks below it as pruned, without deleting anything. A pruned node only keeps recent blocks, and otherwise the proactive scan and the fetches of missing parents would download the whole history, only for the pruner to delete it.
